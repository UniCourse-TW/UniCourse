# Institutions master list (`institutions.json`)

Every Taiwanese 大專校院 in the Ministry of Education open data, one object per school (shape in
`docs/stage3-contract.md`). Generated by `scripts/build-institutions.py`; do not hand edit, rerun:

```sh
python3 -I scripts/build-institutions.py            # downloads the CSV files below
python3 -I scripts/build-institutions.py --from DIR # or reads saved copies (u1_new.csv, higherr.csv, highera1.csv)
```

## Mapping

- Only the newest academic year of each file is used, so closed and merged schools (present only in
  earlier years) are excluded.
- `code`: 學校代碼 as published, a 4-character string. 名錄 codes are digits with leading zeros kept
  (`0001`); religious and open-university codes contain a letter (`1R02`, `0A01`).
- `kind`: from the name suffix: `…專科學校` → `junior_college`, `…學院` → `college`, `…大學` → `university`.
- `ownership`: 公立 (national and municipal) → `public`, 私立 → `private`. Religious colleges are
  private; both open universities are public.
- `system`: 名錄 體系別 [1]一般 and [3]師範 → `general` (MOE statistics count teacher-education
  universities among general universities), [2]技職 → `technical`; dataset 6236 → `religious`;
  dataset 6237 → `open`, keeping only the two 空中大學 rows (the 附設進修學院 / 空中進修學院 rows are
  divisions of schools already listed).
- `military_police`: none. Military and police academies (國防部 / 內政部) are not in the MOE open
  data, so no rows are invented for them.
- `city`: 縣市名稱 without its numeric prefix (`[38]臺北市` → `臺北市`); `null` for the open
  universities (dataset 6237 has no city column).
- `website`: 網址 verbatim (often `http://`); `null` outside the 名錄 (datasets 6236/6237 have none).
- `nameEn`: the MOE files have no English names; set only for the 12 crawler schools (from
  `crawlers/kit/src/schools.ts`), otherwise `null`.
- `slug`: the crawler slug, matched by exact MOE name; the script fails if any of the 12 is missing.
