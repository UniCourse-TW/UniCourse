# UniCourse development

- `crates/catalog` owns the PostgreSQL schema and read queries. Add migrations; do not edit applied migrations. Keep school, course and term-specific offering identities separate.
- `crates/ingest` validates and imports one complete school/term snapshot per transaction. The field contract is `docs/snapshot-format.md` (v2; every v2 field is optional, so v1 files stay valid) and must match `crawlers/kit/src/schema.ts` exactly. Crawlers live under `crawlers/` (see `docs/crawlers.md`); keep them out of the web and API processes. Never commit credentials or snapshots containing private data.
- `crates/api` owns the HTTP contract: catalog (`/api/schools[/{school}[/departments/{department}]]`, `/api/terms`, `/api/departments`, `/api/courses`, `/api/courses/{id}`, `/api/instructors/{school}/{name}`, `/api/rankings/courses`, `/api/stats/overview`) and community (`/api/auth/*`, `/api/users/{username}`, `/api/courses/{school}/{courseCode}/ratings[/stats|/me]`, `/api/posts[/{id}[/replies|/vote]]`); `docs/stage2-contract.md` is the stage 2 spec. Errors are always `{message}` (400 validation, 401 signed out, 403 forbidden). After changing it, run `just codegen`; never hand edit `openapi.json` or `packages/api-client/src/schema.ts`.
- Sessions, login rate limits, ratings and posts live in PostgreSQL (the API may run as several containers); the API runs migrations on start. `COOKIE_SECURE=1` adds `Secure` to the `uc_session` cookie (set in production, off locally). User text is stored as plain text and must never be rendered as raw HTML.
- `course_rankings` is a materialized view; `import` refreshes it after every committed snapshot, so code that writes offerings outside `import` must call `unicourse_catalog::refresh_rankings`.
- `apps/web` uses Svelte 5 runes and loads catalog data via the generated client on the server. Business rules belong in Rust.
- Run `just db` and then `just check`, the same checks as CI. Preserve an e2e path that works with the synthetic fixtures (`just seed`), without live school websites or secrets.
