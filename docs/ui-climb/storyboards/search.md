# search — `/?q=…`

## 使用者任務

輸入「資料結構」後，在一屏內看出哪幾所學校、哪些學期、哪個系開了這門課、誰教、幾學分、什麼時間，然後點進最合適的那一班。也要能把結果縮到「只看清大」「只看 115-1」「只看資工系」而不重打關鍵字。

## 可用資料

- `GET /api/courses?q=&school=&term=&department=&limit=50` → `Offering[]`（id、school、schoolName、term、courseCode、classCode、title、titleEn、instructors[]、department、credits、requirement/requirementText、schedule[]/scheduleText、capacity、enrolled、language、campus、isDemo）。
- `GET /api/schools`、`GET /api/terms`、`GET /api/departments?school=`（系所清單，只有選了學校才有意義）。
- 目前上限 50 筆且沒有總數；要做「共 N 筆、第 1–50 筆」與分頁需要 API 加 `offset` 與 `total`（或 `hasNext`）。在那之前顯示「顯示前 50 筆，請縮小範圍」。
- 沒有排序參數；先以 API 順序（學期新→舊）呈現，排序按鈕在前端做（50 筆內可行）。

## 借用的家族模式

| 元素 | 借自 | 為什麼 |
| --- | --- | --- |
| 頁首「搜尋『關鍵字』」+ 計數行 | site「已收錄 30 個網站・2026 年 10 月」 | 結果數與範圍先講 |
| 工具列 + chip 列（學校／學期帶數量） | site 完整數據頁的標籤 chip | 不用重打關鍵字就能縮小；chip 數字就是分布圖 |
| 結果表：sticky 首欄、數字右對齊、排序箭頭 | site `.ranking-table`、tag `table-styles` | 37 筆 × 9 欄的比較只有表格做得到 |
| 手機改卡片但保留全部欄位 | yt `cross-site-consistency.md` 的 `/live/current` 決策 | 課名 + 8 欄在 390 px 下 sticky 首欄會只剩 60 px |
| 人數欄內的小條 | site 排行條 | 72/80 比文字更快讀出「快滿了」 |
| 分頁列「顯示 1–37 筆・共 37 筆」+ 上一頁／下一頁 | yt `Pagination.tsx` | 用語一致 |

## 要加的圖表

- 人數欄：`enrolled/capacity` 迷你條（capacity 為 0 或 null 時只顯示數字或 `—`）。
- chip 列的數字本身就是直方圖；桌機可在 chip 後畫 4 px 高的比例條（選配）。

## 互動

- 工具列的 select 改變即送出（JS），表單仍是 GET，URL 可分享。
- 系所 select 依所選學校動態載入（`/api/departments?school=`），無 JS 時顯示全部系所文字輸入。
- 表頭排序：前端排序當前 50 筆；`aria-sort` 同步。
- 列點擊到 `/courses/{id}`；教師、系所是獨立連結（分別到 instructor、department 頁）。
- 導覽列的搜尋框與本頁同步 `q`。

## 狀態

- 無結果：Frame 2；提供「查全部學期」（最常見原因是學期預設只看最新）。
- 超過 50 筆：表格底「只顯示前 50 筆，請加上學校或學期」；API 支援分頁後改為真分頁。
- API 失敗：503 頁面保留搜尋框與「重試」。
- 載入：導覽列進度條；結果區不做骨架（SSR）。
- 無 JS：表單 GET 可用；排序按鈕隱藏（`noscript` 樣式）。

## 驗收標準

- task：從輸入到看到結果一次送出；縮小範圍一次點擊（chip）。
- hierarchy：計數行 → 篩選 → 結果 → 分頁；h1 只有一個。
- density：桌機一屏 ≥ 12 列；欄寬固定、課名欄 `max-width 20rem` 截斷有 title。
- viz：人數條與 chip 數字為真實比例。
- family：表格框、chip、工具列規格與 site 一致。
- type：表格 14/20；卡片標題 15 px 600。
- mobile：卡片不裁切任何欄；chip 列可橫捲且有漸層提示。
- theme：列 hover、chip 選中在深色下仍可辨。
- a11y：表頭 `scope`、排序 button 有 `aria-sort`；卡片是 `<article>` 含標題連結；chip 是 `<a aria-current>`。
- states：無結果、超過上限、API 失敗三種皆有專屬文案。
- copy：「班次」「開課單位」「必選修」「人數上限」沿用課程頁用詞。
- feel：select 改變即送出時按鈕顯示 pending；結果區高度不跳。

## 本頁最大的改變

結果從「每筆一張卡」改為桌機資料表 + 學校／學期 chip 分布，手機才用卡片；加入人數條與排序。
