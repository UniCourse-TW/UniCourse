# thread — `/forum/{id}`

## 使用者任務

讀一篇文與所有回覆，知道它在講哪所學校的哪門課並能跳過去；推或噓、回覆；作者能編輯或刪除。

## 可用資料

- `GET /api/posts/{id}` → `PostDetail{…PostSummary 欄位, content, myVote, replies: Reply[]{id, author, content, score, myVote, createdAt, updatedAt}}`。
- `POST /api/posts/{id}/replies`、`PUT /api/posts/{id}/vote`、`PATCH/DELETE /api/posts/{id}`。
- 課程摘要：`GET /api/courses?school=&q=courseCode&term=all` 取最新班次作「課程卡」（課名、教師、評價）。

## 借用的家族模式

| 元素 | 借自 | 為什麼 |
| --- | --- | --- |
| 文章頁 + 右側「相關實體」卡 | tag 文章頁（右欄媒體／標籤資訊）、yt 影片頁的頻道卡 | 討論串要連回課程；右欄是家族的標準位置 |
| 作者行 `@id · 時間 · 已編輯` 13 px muted | tag `AuthorCredits` | — |
| 推噓按鈕改成 pill 組（32 px 高、`aria-pressed`） | yt `Charts` 的 pill group、puma tabs | 現在兩顆 40 px 圓鈕太重 |
| 編輯／刪除改成文字連結 + 確認對話（`<details>` 保留無 JS） | site 管理表「quiet」按鈕 | 降低危險動作視覺重量 |
| 回覆表單固定在最後，字數計數在右下 | course 評分表單規格 | — |

## 要加的圖表

無（viz = null）。分數正負色同 forum。

## 互動

- 推噓即時更新（`use:enhance`），按下時按鈕 pending 態。
- 刪除：`<details>` 內確認（現有），改成右對齊小字 + 紅色確認鈕。
- 回覆成功後捲到新回覆並 `aria-live` 宣告。
- 「這門課」卡：課號無對應課程時不顯示卡，只顯示文字。

## 狀態

- 404／已刪除：現有 `+error.svelte`，改用 states 版型 + 「回論壇」「搜尋課程」。
- 回覆 0：「還沒有回覆，說點什麼？」。
- 未登入：推噓顯示分數文字 +「登入後即可回覆與投票」（現有）。

## 驗收標準

- task：回覆框在頁尾一屏內可達（手機有「回覆」錨點）。
- hierarchy：文 → 課程卡 → 回覆 → 表單。
- density：回覆列間距 12 px、分隔線；不用卡片包每則回覆。
- family：右欄卡、作者行、pill 規格一致。
- type：正文 15/1.8 `max-width 52em`。
- mobile：課程卡在文後；推噓 ≥ 44 px 寬。
- a11y：推噓 `aria-pressed`、分數 `aria-live="polite"`；回覆 `<article aria-labelledby>`。
- states／copy／feel：通則。

## 本頁最大的改變

加入「這門課」側欄卡（連回課程與其他討論），推噓與編輯／刪除改成輕量控制列。
