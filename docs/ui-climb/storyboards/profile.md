# profile — `/u/{username}`

## 使用者任務

看一個人評過哪些課、給幾分、寫了哪些文章，判斷這個人的評價可不可信（活躍度、學校）；是自己時能進設定。

## 可用資料

- `GET /api/users/{username}` → `PublicProfile{username, displayName, school, bio, createdAt, ratings: UserRating[]{school, courseCode, title, score, review, updatedAt}, posts: PostSummary[]}`。
- `GET /api/schools` 給學校名。

## 借用的家族模式

| 元素 | 借自 | 為什麼 |
| --- | --- | --- |
| 頭像（首字母圓形 `--brand-wash`）+ 名稱 + handle 行 | site `.avatar`、tag `AccountMenu` | 家族沒有上傳頭像，用首字母圓 |
| 統計磚 + 分布條 | site `.stats` | 可信度一眼可見 |
| 評價表（桌機）／卡（手機） | search 規格 | — |
| 文章列表 | forum 規格 | — |

## 要加的圖表

- 給分分布 1–5 星迷你直方圖（水平，同課程頁直方圖的縮小版）。

## 互動

- 課程連結到 `/courses/{latestOfferingId}`（需 API 回 id；目前連到搜尋）。
- 排序：最新／分數。

## 狀態

- 404：現有 `+error.svelte` 改 states 版型。
- 評價 0／文章 0：各區一行空狀態（現有文案）。
- 自己的頁：顯示「編輯個人資料」。

## 驗收標準

- task：評價與文章一屏內可掃。
- hierarchy：身分 → 數字 → 評價 → 文章。
- density：評價表每列 ≤ 2 行。
- viz：分布條比例正確。
- a11y：星星 `role="img" aria-label="4 分"`；頭像 `aria-hidden`。
- 其餘通則。

## 本頁最大的改變

加入頭像、統計磚與給分分布，評價改為表格。
