# settings — `/settings`

## 使用者任務

改顯示名稱、自我介紹、所屬學校；看自己的帳號資訊；登出；知道哪些資料會公開。

## 可用資料

- `GET /api/auth/me` → `Me{username, displayName, school, bio, isAdmin, createdAt}`；`PATCH /api/auth/me{displayName?, bio?, school?}`。
- `GET /api/schools`。
- 之後可能加：變更密碼、刪除帳號（API 尚無）。

## 借用的家族模式

| 元素 | 借自 | 為什麼 |
| --- | --- | --- |
| 左側設定導覽 + 右側面板 | tag `/my`、site 管理頁 | 家族設定頁的標準版面；現在只有一個表單但預留擴充 |
| 面板標題下一行「這些資料會…」 | yt 面板 `.panel p` | 隱私透明 |
| 字數計數在 label 右側 | course 評論表單 | — |
| 「已儲存 ✓」inline status | yt `RefreshControl` | 不用整塊綠底 |

## 要加的圖表

無（viz = null）。

## 互動

- 儲存後 `role="status"`「已儲存」3 秒淡出（無 JS 保留）。
- 所屬學校 select 同 auth 規格。
- 登出按鈕是表單 POST（現有）。

## 狀態

- 未登入：導向 `/auth?next=/settings`（現有）。
- 儲存失敗：alert 保留輸入（現有）。
- API 失敗：alert。

## 驗收標準

- task：三個欄位一顆按鈕；登出可見。
- hierarchy：公開資料 → 帳號。
- density：面板 gap 16 px；桌機兩欄。
- family／type／mobile／theme／a11y（label 綁定、計數 `aria-live="polite"`）／states／copy／feel：通則。

## 本頁最大的改變

拆成「公開資料」與「帳號」兩個面板並加左側設定導覽與隱私說明，字數計數移到 label 列。
