# department — `/schools/{slug}/departments/{name}`

## 使用者任務

看一個系所這學期開了哪些課（像系上的課表），以及切到別的學期比較；找特定教師的課；一眼看出必修／選修分布與人數。

## 可用資料

- `GET /api/schools/{school}/departments/{department}` → `DepartmentOfferings{school, schoolName, department, total, offerings: Offering[]}`（目前只回最新 N 筆，前端依 term 分組）。
- 需要分頁或 `term` 參數：建議 API 加 `?term=` 與 `total` 以便「依學期切換」；在那之前前端以現有資料分組。
- `Offering` 欄位同 search。

## 借用的家族模式

| 元素 | 借自 | 為什麼 |
| --- | --- | --- |
| 學期分頁 pill 列 | yt `.tabs`、tag `SectionTabs` | 「切學期」是本頁第二重要的動作，不能藏在 select |
| 必修／選修分布一行 | site 頁首的「已收錄 30 個網站・2026 年 10 月」計數行 | 分布是這頁唯一的統計 |
| 課程表（桌機）／卡片（手機） | search 的同一規格 | 一致 |
| 人數條與評價欄 | site 排行條、tag 分數欄 | 系課表加上熱門度與評價才值得來 |

## 要加的圖表

- 必修／選修／通識分布：一行文字 + 100% 堆疊細條（`--series-1/2/3`）。
- 人數條、評價星數（需 ratings stats 批次端點，或先只顯示有評價者）。

## 互動

- 學期 pill 是連結（`?term=`）；「全部」顯示分組列表（現有）。
- 表頭排序：課名、人數、年級。
- 教師名連到 instructor 頁。

## 狀態

- 該學期無課：「115-1 這個系沒有開課紀錄」+ 其他學期 pill。
- 超過 N 筆：現有「僅顯示最新 N 筆」改成分頁。

## 驗收標準

- task：切換學期一次點擊；首屏看得到本學期課表。
- hierarchy：頁首 → 學期列 → 分布 → 表。
- density：桌機 ≥ 14 列／屏。
- viz：堆疊條與人數條比例正確。
- family／type／mobile／theme／a11y／states／copy／feel：同通則；學期 pill `aria-current`。

## 本頁最大的改變

以學期 pill 取代按學期分組的卡片長列，課程改為可排序的系課表。
