# school — `/schools/{slug}`

## 使用者任務

認識一所學校的資料：收錄了哪些學期、有多少班次與課程、哪些系所開最多課、哪些課歷年最多人修；從這裡再往下到系所或課程，或直接「搜尋這所學校的課程」。

## 可用資料

- `GET /api/schools/{school}` → `SchoolDetail{slug, name, nameEn, terms[], offerings, courses, departments: DepartmentCount[]{name, offerings, courses}}`。
- `GET /api/rankings/courses?school={slug}&limit=10` → 該校排行。
- `GET /api/institutions` 中對應項：status、note、latestImportedAt、website、city。
- 每學期班次數序列目前沒有端點；建議 `SchoolDetail` 加 `byTerm: {term, offerings, enrolled|null}[]`（一個 GROUP BY）。在那之前用 `terms.length` 文字。

## 借用的家族模式

| 元素 | 借自 | 為什麼 |
| --- | --- | --- |
| 頁首 meta 行（英文名・城市・類型・狀態・更新） | yt 頻道頁、site 網站頁 | 實體頁的標準頁首 |
| 統計磚 | site `.stats` | 五個數字 |
| 每學期長條 | yt `Charts.tsx` 的時間序列、puma 流量長條 | 讓「收錄 20 學期」可見，也看出缺學期 |
| 系所表 + 比例條 + 頁內搜尋 | tag 媒體表、site 標籤表 | 112 個系所用卡片格太長；表 + 條可比大小 |
| 兩欄（系所／排行） | tag `split` 版面 | 桌機空間利用 |

## 要加的圖表

1. **每學期班次數長條**（需 `byTerm`）；hover 顯示「113-1：4,980 班次、修課 61,220 人」。
2. **系所比例條**：以最大系所為尺度。
3. **排行條**：同首頁規格。

## 互動

- 系所頁內搜尋（前端過濾，無 JS 時全部展開）。
- 系所表排序：班次／課程／名稱。
- 「搜尋這所學校的課程」帶 `school` 與 `term=all`。

## 狀態

- 無資料（slug 存在但沒匯入）：現在是 404；改為 200 頁顯示學校基本資料 + 狀態 + 說明 +「看全國狀態」（因為 `/schools` 已有這所學校的列）。
- `byTerm` 只有 1 期：圖隱藏。
- 排行為空：隱藏右欄。

## 驗收標準

- task：第一屏就有「搜尋這所學校」與數字。
- hierarchy：頁首 → 磚 → 時間 → 系所／排行。
- density：系所表每列 36 px；桌機兩欄。
- viz：長條缺學期留空；比例條同尺度。
- family：與 site 網站頁一致。
- type／mobile／theme／a11y／states／copy／feel：同 design-language 通則；長條有數值表 `<details>`。

## 本頁最大的改變

系所從卡片格改為「有比例條的表」，並加入每學期班次長條與該校前 10 排行。
