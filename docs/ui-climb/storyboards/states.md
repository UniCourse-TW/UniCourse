# states — 空、載入、錯誤、404、無 JS

家族規則（site `.empty`、yt `ReportUI`、tag `not-found.tsx`）：狀態都在「內容原本的位置」出現，保留頁首與篩選，不整頁取代；「沒有資料」「暫時無法取得」「0」三者永遠分開；每個狀態都有一個明確下一步。

## 1. 空狀態（Empty）

```
┌──────────────────────────────────────────────┐
│                                              │
│           找不到「zzzz」的課程                 │   ← 16 px 600 `--ink-2`
│   換個關鍵字、改選「全部學期」，或試試課號。     │   ← 13 px muted，最多兩行
│        [查全部學期]   清除篩選                 │   ← 一顆次要按鈕 + 一個文字連結
│                                              │
└──────────────────────────────────────────────┘
   在表格框／列表框內置中，padding 48 px 18 px；外框保留（邊線、圓角、面板底）。
```

| 頁 | 標題 | 說明 | 動作 |
| --- | --- | --- | --- |
| search | 找不到「{q}」的課程 | 換個關鍵字、改選「全部學期」，或試試課號。 | 查全部學期／清除篩選 |
| home 排行 | 還沒有可排行的課程 | 匯入學期資料後會自動出現。 | 看各校收錄狀態 |
| schools 篩選 | 沒有符合的學校 | — | 清除篩選 |
| school 系所 | 這所學校還沒有開課單位資料 | — | 搜尋這所學校 |
| department 學期 | {term} 這個系沒有開課紀錄 | — | 其他學期 pill |
| course 評價 | 還沒有人評價這門課 | 成為第一個？ | 評分表單（登入）／登入 |
| course 外部 | 還沒索引到相關文章 | — | 到其他網站搜尋 pills |
| course 歷年 | （只有 1 期）隱藏圖，不顯示空狀態 | — | — |
| forum | 還沒有文章，來發表第一篇吧。 | — | 發表文章 |
| forum 篩選 | 沒有符合的文章 | — | 清除篩選 |
| thread 回覆 | 還沒有回覆，說點什麼？ | — | 回覆框 |
| profile | 還沒有評價任何課程／還沒有發表文章 | — | — |

## 2. 載入（Loading）

- 全站以 SSR 為主，首次載入不顯示骨架。
- 換頁：導覽列下緣 2 px `--brand` 進度條（tag `NavPending`），`prefers-reduced-motion` 時改為靜態滿寬條。
- 局部（`use:enhance` 表單、select 即送出）：按鈕進入 pending（`aria-busy`、文字不變、透明度 .6、禁止重送）；表格區 `aria-busy="true"` 且內容保留（不清空、不位移）。
- 延遲載入的圖表（若用 ECharts）：先畫同尺寸的 `--panel` 區塊 + 一顆 `--brand` 圓點「載入圖表…」；失敗改顯示數值表。

```
│ ● 載入中…          ← 8 px 圓點 + 14 px muted，置中，padding 64 px │
```

## 3. 錯誤（Error，非 404）

```
┌──────────────────────────────────────────────┐
│ ▍暫時無法取得課程資料                          │   ← 左側 3 px `--down` 邊、`--panel` 底、radius 8
│   請稍後再試；查課以外的頁面不受影響。          │
│   [重試]                                       │
└──────────────────────────────────────────────┘
```

- 區塊級（API 一部分失敗）：在該區原位置顯示；其他區正常。例如 course 頁評價失敗，課程資料仍顯示。
- 頁級（503）：保留導覽列與搜尋框；主內容換成上面的區塊；`<title>` 為「暫時無法顯示｜UniCourse」。
- 表單級：`role="alert"` 紅底區塊，文案來自 `community-messages.ts`。
- 統計數字失敗一律顯示 `—` 並附註「暫時無法取得」，不顯示 0。

## 4. 404

```
┌──────────────────────────────────────────────┐
│ [logo]                                        │
│ 找不到這門課程                                 │   ← h1 20 px
│ 可能已被校方移除，或網址有誤。                   │
│ [搜尋課程]  回首頁                             │
│ 你也可以：看各校收錄狀態 · 逛逛論壇              │
└──────────────────────────────────────────────┘
```

| 路由 | 標題 | 動作 |
| --- | --- | --- |
| `/courses/{id}` | 找不到這門課程 | 搜尋課程 |
| `/schools/{slug}` | 找不到這所學校 | 看各校收錄狀態 |
| `/schools/{slug}/departments/{name}` | 找不到這個開課單位 | 回學校頁 |
| `/instructors/{school}/{name}` | 找不到這位教師 | 以姓名搜尋課程 |
| `/forum/{id}` | 找不到這篇文章，可能已被刪除 | 回論壇 |
| `/u/{username}` | 找不到這位使用者 | 逛逛論壇 |
| 其他 | 找不到這個頁面 | 回首頁 |

- 用根層 `+error.svelte` 統一樣式；現有 `forum/+error.svelte`、`u/+error.svelte` 改用共用元件。
- 404 頁也要有完整導覽列與 footer，深色正常。

## 5. 無 JS

- 所有篩選與表單都是原生 GET/POST（現有）；「改變即送出」只在 JS 時啟用，無 JS 顯示「套用」按鈕。
- 排序按鈕、密碼顯示切換、chip 輸入在 `<noscript>` 樣式下隱藏或退化為文字輸入。
- 圖表全部是 SSR 的 inline SVG／CSS 條，無 JS 可見；ECharts（若用）以數值表為替代。
- 主題：無 JS 時跟隨 `prefers-color-scheme`（`:root:not([data-theme="light"])` 規則），切換鈕隱藏。
- `<details>` 用於折疊（表單、目錄、歷年表），無 JS 原生可用。

## 6. 驗收標準（states 維度）

- 每頁的截圖集至少包含一個空或 404 狀態（`ui-shots.mjs` 已附 `search-empty`、`notfound`）。
- 空狀態與錯誤狀態在深色下有邊框或底色區分。
- 404 與錯誤頁 `<title>` 正確、有 h1、有 ≥ 2 條出路。
- 任何 API 失敗不會讓數字顯示為 0。
- `prefers-reduced-motion` 時沒有動畫。
