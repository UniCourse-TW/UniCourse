# legal — `/terms`、`/privacy`

## 使用者任務

在註冊前或疑慮時快速讀懂：資料從哪來、哪些會公開、Cookie 用途、外部評論的收錄原則（只索引摘要、可要求移除）。

## 可用資料

- 靜態內容（現有兩頁）；需新增「外部評論與移除請求」段落（對應 plan.md 的收錄原則：只存連結、標題、作者 handle、日期、看板、推數、≤ 120 字摘要；不轉載全文、不用於訓練；依 `Content-Signal` 判斷）。
- 更新日期（寫死於頁面）。

## 借用的家族模式

| 元素 | 借自 | 為什麼 |
| --- | --- | --- |
| `doc-layout` 左目錄 + 正文 | site API 文件頁（`.doc-layout/.doc-toc`）、tag `/method` | 家族的文件頁版面 |
| 更新日期在頁首右 | yt 頁首「更新於」 | — |
| 正文 15/1.9、`max-width 52em`、h2 20 px 上距 28 px | yt `.prose` | 可讀性 |

- 無（靜態）；無 JS 完整可用。

## 驗收標準

- task：兩頁都在一屏內有目錄。
- hierarchy：h1 → 日期 → h2 段落。
- density：段落不超過 5 行。
- family：版面與 site 文件頁一致。
- type：行高 1.8–1.9；CJK 標點不懸掛。
- mobile／theme／a11y（目錄是 `<nav aria-label="目錄">`）／states／copy（Taiwan usage：「隱私權政策」「使用條款」）／feel：通則。
