# instructor — `/instructors/{school}/{name}`

## 使用者任務

「這位老師教什麼、教了幾年、課評價如何、網路上怎麼說？」看老師歷年開的課、每期人數、評價，並從這裡進到某一班。

## 可用資料

- `GET /api/instructors/{school}/{name}` → `InstructorOfferings{school, schoolName, name, summary: InstructorSummary{offerings, courses, terms[], departments[]}, offerings: Offering[]}`（最新 N 筆）。
- 評價：每門課 `GET /api/courses/{school}/{courseCode}/ratings/stats`（需批次或 API 加 `ratings` 到 offerings；在那之前以逐課請求限制在前 10 門）。
- 外部評論：`GET /api/courses/{school}/{courseCode}/external-reviews` 以 `matched.teacher === name` 篩選，或日後 `GET /api/instructors/{school}/{name}/external-reviews`。
- 同名不同人無法分辨：頁首要說明「同校同名教師會合併顯示」。

## 借用的家族模式

| 元素 | 借自 | 為什麼 |
| --- | --- | --- |
| 人物頁首（名字、所屬、期間、口徑註） | tag 記者頁（`/journalist`）、puma 人物面板 | 同樣是「以名字聚合的實體」，需要口徑說明 |
| 統計磚 | site | — |
| 課程 × 學年點陣 | tag 關鍵字歷史（`TagKeywordHistory`）、puma 熱度 | 一眼看出教了幾年、哪些課固定開 |
| 開課表 + 篩選 | search 規格 | — |
| 外部評論列 | course 規格 | 教師評論是 PTT 課程版最常見的主題 |

## 要加的圖表

1. **課程 × 學年點陣**：列 = 課程（最多 8，其餘折疊），欄 = 學年；有開課畫圓點，直徑依人數分三階（`--seq-2/3/4`）；hover 顯示「113 學年：2 班、156 人」。
2. **人數條**、**評價**：同 search。

## 互動

- 點陣的點可點，到該學期該課的班次。
- 列表的學期／課程 select 前端篩選。

## 狀態

- 查無此師：404 版型 +「搜尋教師名」連結到 `/?q=`。
- 評價 0：磚顯示「— 還沒有評價」。
- 外部 0／失敗：同 course。

## 外部評論（external reviews）區塊規格

- 與 course 相同元件；標題「網路上的討論（N）」；副標「以教師姓名與學校比對的公開文章摘要。」
- 每則標示匹配到的課程（`資料結構`）作 chip；若一則文章匹配多門課只顯示一次。
- 「到其他網站搜尋」的連結以教師名為關鍵字（例如 PTT 全站搜尋 `王小明 清大`）。
- 口徑註：「摘要來自公開搜尋結果，不轉載全文；若有錯誤比對請回報。」

## 驗收標準

- task：第一屏就知道教幾年、幾門、評價。
- hierarchy：頁首 → 磚 → 點陣 → 列表 → 外部。
- density：列表為表格；點陣每列 28 px。
- viz：點大小三階有圖例；缺學年留空。
- a11y：點陣有 `<table>` 替代（視覺隱藏）或 `aria-label` 摘要；外部連結標示外部。
- states：404、評價 0、外部 0／失敗。
- 其餘同通則。
