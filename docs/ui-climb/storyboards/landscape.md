# landscape — `/landscape.html` → `/landscape`

## 使用者任務

看全國各校「課程網站長什麼樣」：官方課程系統、第三方選課／評價網站（歐趴糖、NCKU HUB、NTU Rating…）、是否可抓、robots 規則；對開發者是爬蟲的地圖，對一般人是「我的學校有哪些查課工具」。

## 可用資料

- 目前是靜態 `apps/web/static/landscape.html`（411 KB，含內嵌資料與自己的 token），由 `docs/landscape.md`／`landscape-schema.md` 產生。
- 搬進 SvelteKit `/landscape` 後資料來源改為 build 時讀取 `data/landscape.json`（或 API `GET /api/landscape`）：每校 `{school, official: Site[], thirdParty: Site[]}`，`Site{name, url, kind, status(ok|blocked|unknown), robots, notes, checkedAt}`。
- 與 `/schools` 的 `status` 連動。

## 借用的家族模式

| 元素 | 借自 | 為什麼 |
| --- | --- | --- |
| sticky 篩選列 + 統計磚 | 現有 landscape.html 已這樣做（`.bar`、`.summary`） | 保留，只換 token 與 nav |
| 每校一段 + 兩個小表 | tag `/crawlers/` 頁（每媒體一段的爬蟲狀態） | 同是「資料來源盤點」頁 |
| 狀態 badge 三色 | `/schools` | 一致 |
| 納入站內 nav 與 footer | 家族每頁同殼 | 現在是獨立 HTML，沒有導覽列 |

## 要加的圖表

- 統計磚；各校段的「可抓／受阻」小圓點。
- 選配：依體系的 100% 堆疊條（可抓／受阻／未知）。

## 互動

- 篩選即時（前端，資料已在頁內）；URL hash 同步。
- 校名錨點 `#ntu`，與 `/schools` 互連。

## 狀態

- 篩選無結果：一行 + 清除。
- 無 JS：全部內容展開，篩選隱藏。

## 驗收標準

- task：搜尋框 sticky，打校名立刻只剩該校段。
- hierarchy：頁首 → 磚 → 第三方總表 → 各校。
- density：各校段只兩行一站；桌機 ≥ 6 校／屏。
- family：有站內 nav、footer；token 同其他頁。
- a11y：段落 `h2` 有 id；外部連結標示。
- mobile：sticky 列不遮內容；磚 2×2。
- 其餘通則。

## 本頁最大的改變

從獨立靜態頁搬進站內殼（導覽、footer、token），加入統計磚與第三方網站總表。
