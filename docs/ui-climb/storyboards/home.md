# home — `/`

## 使用者任務

一到站就能打關鍵字開始查課；還沒想好要查什麼的人，看得到「哪些課歷年修課人數最多」和「目前收錄了多少學校、學期」，並從排行或學校直接點進去。三秒內要能回答「這個站是什麼、資料有多少、現在能查什麼」。

## 可用資料

- `GET /api/schools` → `School[]`（slug、name、nameEn）；`GET /api/terms` → `string[]`（新到舊）。
- `GET /api/rankings/courses?school=&limit=` → `CourseRanking[]`（school、schoolName、courseCode、title、titleEn、terms、offerings、enrolledTotal|null、capacityTotal|null、latestOfferingId、isDemo），已依 enrolledTotal DESC NULLS LAST 排序。
- `GET /api/stats/overview` → `SchoolOverview[]`（offerings、courses、terms、latestImportedAt）+ `totals`。
- `GET /api/institutions` → 150 所 + 狀態，用來算覆蓋 chip（live 9、partial 1、blocked 2）。
- 尚無「每學期累計人數序列」端點；排行列的 sparkline 需要新增 `GET /api/rankings/courses` 回傳 `byTerm: {term, enrolled|null}[]`（建議由同一聚合查詢順便回傳），在那之前以「開課學期數」文字替代。

## 借用的家族模式

| 元素 | 借自 | 為什麼 |
| --- | --- | --- |
| masthead 一句話 + 資料範圍行 | tag 首頁 wordmark 下「同一件事，各台怎麼說」+ 更新時間 | 首頁要先講清楚「這是什麼、資料多新」 |
| 一列搜尋框 + 兩個 select-field + 實心按鈕 | site 首頁工具列、yt `/channels` | 查課是主任務，必須在首屏且一行完成 |
| 5 格統計磚 | site `.stats`、yt `.metrics` | 把「資料有多少」變成可掃的數字，不再是段落 |
| 排行表（# 欄、主體欄、右對齊數字、條、走勢） | site 流量排行、tag 關鍵字排行 | 現在的 `<ol>` 卡片無法對齊與比大小；表格 + 同尺度條才能比 |
| 「完整排行 →」只放前 10 | yt 首頁「熱門標籤 完整排行 →」 | 首頁是摘要，不是完整清單 |
| 學校覆蓋熱度條 | puma 縣市著色 + site 「資料收集中」chip | 10 學年 × 9 校的覆蓋是本站最大賣點，要一眼看出 |

## 要加的圖表

1. **排行條**：`enrolledTotal / max` 寬度，前三名實心紫，其餘 60%；capacity 替代時用斜紋（`repeating-linear-gradient`）+ 「名額」字樣，顏色 `--warn`。
2. **走勢 sparkline**（需要 `byTerm`）：每學期 enrolled，缺值斷線，96×32。
3. **學校覆蓋熱度條**：每校 10 格（學年 106–115），有資料的格子 `--seq-4`、部分 `--seq-2`、沒有 `--seq-0`；hover/focus 顯示「113 學年：2 學期、12,345 班次」。

## 互動

- 搜尋框 `autofocus` 不開（手機會跳鍵盤）；Enter 送出；桌機導覽列的全站搜尋與頁內搜尋共用 `?q=`。
- 排行的學校 select 改變即送出（有 JS）；無 JS 時保留「套用」按鈕。
- 排行列整列可點（連到 `latestOfferingId`），鍵盤 focus 在課名連結。
- 熱門關鍵字 chips 是預填連結（`/?q=資料結構&term=all`），由近 7 日搜尋或人工清單產生。

## 狀態

- 排行為空（新環境）：表格框內置中「還沒有可排行的課程」+ 「看各校收錄狀態」連結。
- API 失敗：統計磚顯示 `—` 與一行「暫時無法取得統計」，搜尋框仍可用（表單是 GET）。
- 載入：SSR，無骨架；換頁時導覽列進度條。
- 無 JS：全部可用（GET 表單、純 SVG）。

## 驗收標準（對應 rubric）

- task：首屏有搜尋框 + 熱門 chips；一次按鍵或一次點擊開始查課。
- hierarchy：順序固定為 masthead → 搜尋 → 統計磚 → 排行 → 覆蓋；每區一個 h2。
- density：排行是表格，數字右對齊 tabular；桌機 10 列不超過 1 屏。
- viz：條依同一尺度繪製、名額替代有視覺區別；覆蓋條每格對應一個學年。
- family：導覽列／工具列／統計磚／表格框與 site、yt 同規格；紫色只在強調。
- type：h1 34 px 僅此頁；正文 15/1.65；表格 14/20。
- mobile：390 px 無橫向捲動；排行列兩行版；觸控 ≥ 44 px。
- theme：深色面板 zinc-900、條色改 `#b79cf0`，截圖兩版皆設計。
- a11y：表格有 caption；sparkline `aria-hidden` 且旁有數字；chip 是連結；focus ring 可見。
- states：空排行、API 失敗各有設計。
- copy：「已收錄」「更新於」「累計修課人數」「名額」用詞一致；不出現「示範」以外的英文術語。
- feel：首屏 SSR 無佈局位移；select 改變即送出有 pending 指示。

## 本頁最大的改變

排行從卡片清單改成「有尺度條與走勢的排行表」，上方加 5 格統計磚與學校覆蓋熱度條，讓首頁像 site.observe.tw 的流量排行而不是一個搜尋框。
