# course — `/courses/{id}`

## 使用者任務

決定「要不要修這門課」：這班誰教、什麼時候上、幾學分、必選修、還有沒有名額；這門課歷年有多少人修（熱門程度）、同學評價如何、網路上（PTT 等）有人討論過什麼；最後一鍵到校方課程頁或課綱。

## 可用資料

- `GET /api/courses/{id}` → `Offering`（全部欄位，含 `enrolled`、`capacity`、`extra`、`sourceUrl`、`syllabusUrl`、`importedAt`、`isDemo`）。
- `GET /api/courses/{school}/{courseCode}/ratings` → `Rating[]`；`/stats` → `RatingStats{average, count, histogram[5]}`；`/me` → `MyRating|null`（登入時）。
- `GET /api/posts?school=&courseCode=&pageSize=5` → 相關討論（`PostSummary[]`，含 replyCount、score）。
- `GET /api/courses?school=&q=courseCode&term=all` 取同課號的其他學期班次 → 做「歷年開課與修課人數」序列（建議 API 新增 `GET /api/courses/{school}/{courseCode}/history` 回傳 `{term, offerings, enrolled|null, capacity|null, instructors[]}[]`，避免前端搜尋）。
- `GET /api/instructors/{school}/{name}` 只在教師頁用；本頁教師名是連結。
- **外部評論**（平行開發中）：`GET /api/courses/{school}/{courseCode}/external-reviews` → `{ indexed: ExternalPost[], links: ExternalLink[] }`。`ExternalPost = {url, title, author, date, board, pushCount, excerpt(≤120字), matched:{school, courseCode?, teacher?}}`，`ExternalLink = {site, label, url}`（OPT 歐趴糖、NCKU HUB、NTU Rating 等只給搜尋連結，不抓內容）。

## 借用的家族模式

| 元素 | 借自 | 為什麼 |
| --- | --- | --- |
| 麵包屑 + h1 + 一行 meta + 右側外部連結 | site 完整數據頁首、yt 頻道頁 | 校方課程頁與課綱是本頁最常用的出口，放頁首右側 |
| 5 格統計磚 | site `.stats`、yt `.metric` | 學分／必選修／人數／歷年／評價是決策的五個數字 |
| 歷年長條圖 + 數值表 `<details>` | puma `traffic-chart`、yt `Charts.tsx` 的「查看數值表格」 | 圖只是摘要，表才可查；缺值畫虛線不畫 0 |
| 評價直方圖（現有）改成 site 排行條規格 | site 排行條 | 現在的直方圖已可用，調成同一條高與色 |
| 外部評論卡：來源 badge + 推數 + 日期 + 標題 + 摘要 + 原文連結 | tag 文章列表項（媒體 icon + 標題 + 摘要 + 時間） | 同樣是「索引他站內容、只展示摘要」的倫理與版面 |
| 「摘要來自公開搜尋結果，不轉載全文」口徑說明 | 家族每張圖的口徑註 | 透明度是家族招牌 |
| 站內討論用兩欄緊湊列表 | tag `CompactArticleList` | 討論在這頁是附屬，不要卡片 |

## 要加的圖表

1. **歷年修課人數長條**：x 軸為學期（106-1 → 115-1，缺學期留空格），y 軸人數；enrolled 為 null 但 capacity 有值時畫虛線框；多班次時加總並在表格列出各班。
2. **人數條**：`enrolled/capacity`，≥ 90% 變 `--warn`。
3. **評價直方圖**：維持，改 token。
4. **教師版本**：表格列出每學期教師，教師名為連結；hover 歷年列 highlight 對應長條。

## 互動

- 評分表單：登入後在評價區內（現有 `?/rate`），送出後局部更新（`use:enhance`）並顯示「已儲存」。
- 外部評論：原文連結 `rel="noopener noreferrer" target="_blank"`，卡片整張可點；「到其他網站搜尋」是純連結列。
- 歷年表格預設 5 列，`<details>` 展開全部。
- 「發表關於這門課的文章」帶 `school`、`courseCode` 到 `/forum`。
- 概述／備註／其他校方欄位在手機收成 `<details>`，桌機展開。

## 狀態

- 沒有歷年資料（只有 1 期）：隱藏圖，只列 1 列表格。
- 評價 0 則：直方圖隱藏，顯示「還沒有人評價這門課，成為第一個？」+ 評分表單。
- 外部評論 API 失敗：「網路討論暫時無法取得」+ 仍顯示搜尋連結列（連結不依賴索引）。
- 外部評論 0 則：只顯示搜尋連結列 +「還沒索引到相關文章」。
- 404：`states.md` 的 404 版型，附「搜尋這個課號」連結。
- 示範資料：頁首 badge「示範」+ 一行說明（現有），不再用整段黃字。

## 外部評論（external reviews）區塊規格

- 標題「網路上的討論（N）」，副標「來自 PTT 課程版等公開看板的搜尋結果；只顯示標題、作者、日期與 120 字內摘要，不轉載全文。」
- 每則：`<article>`：第一行 board badge（`PTT NTHU_Course`）+ `推 23` + 日期；第二行標題連結（外部）；第三行摘要 2 行截斷；匹配到教師時標 `符合教師：王小明` 小字。
- 排序：推數 × 近期性；最多 6 則，`<details>` 展開到 20。
- 「到其他網站搜尋」：每站一顆 pill（`--chip`），文案「PTT 全站」「歐趴糖」「NCKU HUB」「NTU Rating」依學校顯示（例如只有臺大顯示 NTU Rating）。
- 每則底部不顯示作者全名以外的個資；作者 handle 以 `@id` 顯示。
- 深色下 board badge 用 `--chip` 底。

## 驗收標準

- task：首屏（桌機 800 px）看得到五格統計磚與校方連結；手機首屏看得到學分、必選修、人數。
- hierarchy：頁首 → 數字 → 時間地點／歷年 → 評價／外部 → 站內討論 → 長文；長文最後。
- density：事實欄位改成磚 + 兩欄，不再是 14 列 `dl`。
- viz：歷年長條比例正確、缺值不畫 0；人數條閾值色。
- family：磚、表、條、badge 規格與 design-language 一致。
- type：h1 24 px；磚數字 28 px；表 14/20。
- mobile：2×2 磚；歷年圖可橫捲；外部評論卡 ≥ 44 px 可點。
- theme：長條與直方圖在深色用 `#b79cf0`；外部卡有邊線。
- a11y：圖有 `role="img" aria-label` 與數值表；外部連結有「（外部）」或 icon + sr-only；評分 radio 有 fieldset/legend。
- states：歷年 1 期、評價 0、外部 0／失敗、404、示範五種皆設計。
- copy：「修課人數」「名額」「歷年」「網路上的討論」「站內討論」固定用語。
- feel：評分送出局部更新；展開 `<details>` 無位移跳動。

## 本頁最大的改變

把 14 列定義清單改成「五格統計磚 + 歷年修課人數長條與各期表」，並在評價旁加入外部評論索引與搜尋連結。
