# forum — `/forum`

## 使用者任務

看最近有哪些修課心得與選課提問，依學校或分類縮小，找到自己學校／課程的討論；登入後發一篇文（常從課程頁帶著課號過來）。

## 可用資料

- `GET /api/posts?type=&school=&courseCode=&tag=&q=&page=&pageSize=` → `PostPage{posts: PostSummary[], page, pageSize, total}`；`PostSummary{id, type, title, excerpt, author{username, displayName}, school, courseCode, tags[], replyCount, score, createdAt, updatedAt}`。
- `GET /api/schools` 給學校名。
- `POST /api/posts`（登入）。
- 沒有「各學校／分類文章數」端點；chip 數量先以當頁結果統計或 API 加 `facets`。

## 借用的家族模式

| 元素 | 借自 | 為什麼 |
| --- | --- | --- |
| 頁首右側主要動作 | yt「套用」紅按鈕位置、tag 頁首動作 | 發文是本頁唯一寫入動作 |
| 工具列 + 分類 chip | site | — |
| 文章列表：tag 文章列（媒體 badge + 標題 + 摘要 + 作者時間）+ 右側數字欄 | tag `ArticleListItem`、`CompactArticleList` | 列表而非卡片；回覆／分數右對齊可掃 |
| 作用中篩選 chip（課號 ×、#tag ×） | site 「非台灣 ×」chip | 現有的「清除」文字改成可關閉 chip |
| 分頁列文案 | yt `Pagination` | — |
| 發文表單收在 drawer | tag `BoardEditor`（yt） | 不讓表單把列表擠下去 |

## 要加的圖表

- 分類 chip 的數量；分數欄用 `--up/--down` 色（正綠負紅、0 muted）。
- 無其他圖。

## 互動

- 未登入點「發表文章」→ `/auth?next=/forum?compose=1`。
- 課號輸入時即時驗證（`/api/courses?school=&q=`）顯示課名 ✓。
- 標籤輸入改為 chip 輸入（Enter 新增，最多 5）。
- 列整列可點；作者、學校課號、標籤是獨立連結。

## 狀態

- 無文章：「還沒有文章，來發表第一篇吧。」+ 按鈕。
- 篩選無結果：「沒有符合的文章」+ 清除。
- 發表失敗：表單內 `role="alert"` 保留輸入。
- 無 JS：`<details>` 版表單仍可用。

## 驗收標準

- task：發文一次點擊開表單；篩選 chip 一次點擊。
- hierarchy：頁首 → 篩選 → 列表 → 分頁；表單不在主流程中。
- density：桌機一屏 ≥ 10 篇；摘要 2 行截斷。
- viz：null（分數色不算圖）。
- family／type／mobile／theme／a11y／states／copy／feel：通則；分類 badge 三色在深色可讀；列表是 `<ol>`，每篇 `<article>`。

## 本頁最大的改變

文章從卡片堆改為 tag 風格的緊湊列表（右側回覆／分數欄），發文表單移到右側 drawer，篩選改 chip。
